# Ambience sources

Each world plays one real field recording from Freesound, all CC0 (public domain, http://creativecommons.org/publicdomain/zero/1.0/). Each file is a stretch of the recording's public HQ preview, high-passed at 40 Hz, levelled to -20 LUFS with peaks limited at -8 dBFS, 0.5 s fades, AAC 96 kbps. Generated and assembled soundscapes were retired on 12 October 2026 (art archive: `retired-soundscapes-2026-10-12`).
