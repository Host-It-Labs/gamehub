# Originality and asset provenance

Gamehub contains Undertow (trick taking), Wildgrove (drafting and placement), and Midnight Market (drafting and set collection). Names, written rules, scoring descriptions, and the tabletop presentation are project content. Names are working titles; no trademark clearance is asserted.

The local illustration assets `public/art/covers-v3.png`, `pieces-v3.png`, and `woodland-board.png` were generated for the tabletop design. They are used directly or as cropped atlases; gameplay makes no external artwork requests. `game-worlds.png` is a retained earlier project illustration. No third-party franchise assets are intentionally included.

Sounds are synthesized with Web Audio in `lib/games/trio/sound.ts`. Icons are provided by lucide-react under its ISC license. Component and runtime dependencies retain their own licenses. Project licensing is PolyForm Noncommercial 1.0.0; see `LICENSE`.
