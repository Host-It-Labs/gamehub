# Arena card portraits v13: text only (9 October 2026)

*Superseded on 10 October 2026 by the cartoon set v14
([2026-10-10-arena-portraits](../../2026-10-10-arena-portraits/README.md)):
William found these too realistic, real-looking people with realistic colour.*

William rejected the v11/v12 restyles: they were made from the v7 cards as base
images, and every pass through a base image turns the colours yellow and the
picture worse. v13 regenerates every card except the Samurai (duelist v10-a)
and Cowboy (ranger v10-b), which he likes, from text alone: one shared style
paragraph written from those two cards' accepted prompts, then each card's
subject (the v7 subjects of docs/concepts/2026-10-01-arena-draft/portraits.md,
or a written description of the figures rebuilt on 4 October). No image was
attached or used as a reference. Two variants per card (-a, -b), generated
with the artwork skill's command (newest Luna, low reasoning).

The exact prompt of each card is in `<id>.txt` beside this file.
