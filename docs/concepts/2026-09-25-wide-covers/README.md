# Wide lid covers (3:1) and a toon Yata square cover

25 September 2026. The setup modal's lid is exactly 3:1; each game gets a
dedicated landscape cover generated at 1536x1024 and centre-cropped to
1536x512 (keeping y 256-768). Yata also gets a new square library cover in its
in-game cel-shaded toon style, replacing the gouache direction the user found
too realistic and detailed.

Fresh text-only generations with Codex `$imagegen`, one image per invocation,
two variants per image, launched in parallel, no reference images and no edits.
Style paragraphs are copied from the shipped cover prompts (as text):
Nox/Mora `2026-09-21-blind-*.md`, Know Me/Quiz `2026-09-23-know-me-quiz-covers`,
Folio/Relic `2026-09-23-folio-relic-covers`. Yata uses the cel-shaded paragraph
from `2026-09-19-yata-counter/README.md` plus a simplicity clause.

Launcher: `gen.sh` in this folder. Codex logs: `logs/`.

## Model note

The first launch of all 16 failed before generating anything: the Codex config
default model `gpt-6-sol` is now rejected ("not supported when using Codex with
a ChatGPT account"; logs in `logs/failed-model/`). `gen.sh` passes
`-m gpt-6-astra` per invocation instead; `~/.codex/config.toml` was not
changed. Image generation itself is the same built-in tool.

## Verification method

Every image was viewed in full and as its actual 3:1 centre crop
(`sips -c 512 1536 --cropOffset 256 0`, in the session scratchpad). Checks:
exact title spelling and no other text; title and key subjects inside the
kept strip with breathing room, nothing important in the discarded quarters;
style against the brief.

## Prompts (exact)

Each file in `prompts/` is the exact prompt text passed after the fixed Codex
preamble ("$imagegen Generate this image using the built-in image generation
tool. Do not edit or revise any image; make exactly one generation and save it
as is. Save the final image to the exact absolute path: <path>. Prompt: ").
