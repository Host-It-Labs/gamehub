# Metro covers, 25 October 2026

The first covers for **Metro** (`metro`), the flip-and-draw metro game built
on 25 October 2026 at William's request ("a replication" of Next Station:
Berlin, with Gamehub's own name, city, look and art). Both covers, the square
library cover and the 3:1 setup-lid `wideCover`, paint the game's own world:
a sunny river city drawn on a panel of hand-painted azulejo tiles (white glaze,
cobalt drawing, soft glaze washes for the districts), the river between the
Moon bank and the Sun bank, and the four line colours (terracotta, cobalt,
olive, saffron) as thick glaze strokes joining circle, square, triangle and
diamond stations. The title "Metro" is lettered with those lines, one colour
per letter, stations on the strokes.

## Generation

Text-only generations, one image per Codex invocation, two variants (`-a`,
`-b`) per image, all four launched at once through `batch.sh` → `gen.sh`
(copied from the 10 October Rota run: `gen.sh` requires exactly one PNG in the
run's own `~/.codex/generated_images/<session id>/` folder and checks the
saved copy by sha256). No reference images, no edits. Model `gpt-6-luna`
(newest Luna from `.claude/skills/artwork/newest-luna.mjs`), low reasoning
effort, codex-cli 0.161.0, stdin closed. Logs in `logs/`, PNGs in `sources/`.
Both variants of an image share the prompt file in `prompts/`.

No border, no decorative frame, no mat, no vignette, no gray padding, no box mockup, no perspective packaging, no UI, no game screenshot, no buttons, no cards held by anyone, no dice, no hands, no arms, no people.
