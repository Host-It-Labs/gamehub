# Yata: the counter from above (19 September 2026)

Redesign of the Yata plates in true plan view (see the "Flat pieces on a painted world" rule in the game-world-layout skill). The previous night-market plates showed the counter in a low three-quarter view, so the flat DOM plates and tickets read as stickers pasted over a photo. The approved toon style paragraph is kept verbatim; the menu chips, tickets, pennants and the red arcade confirm stay.

Every image below is a fresh generation from the prompt text alone; no image was opened while writing prompts. Two variants per orientation (`-a`, `-b`), launched in parallel.

Both orientations failed the same way on the top band with both variants, so a retry from the same text was judged unlikely to change it; the deviation is benign for the runtime (the stage rule keeps the counter inside the play area, the extra band above is cropped or covers the pennant row) and was accepted rather than spending the retry budget.

## Integration for review

- `lib/games/yata-world-landscape.json` and `yata-world-portrait.json` now describe the `-a` plates. The `table` box is the **intersection** of the a and b counters (landscape 302–1234 × 234–650; portrait 96–930 × 355–766) so that both candidates line up under the same plate grid; the chosen one can get its exact box afterwards. Landscape `signboards` are the blank menu boards (100–265 × 335–625 and 1270–1435 × 335–625), inside both candidates' boards; portrait has none (its controls live in the dock).
- `lib/games/table-world-variants.json` registers `yata-counter-a` and `yata-counter-b` per orientation, so the floating switcher (already mounted for world tables) flips between them.
- `node scripts/optimize-paper-worlds.mjs` derived the WebP plates and overviews.
- `components/game/table-worlds.css`: the menu-board pins read `--board-left-x`, `--board-right-x`, `--board-top`, `--board-width` (plate source pixels) instead of hard-coded offsets; plates carry a per-dish ring (cream, cobalt, mustard, green, charcoal, peach; no red ring on the red enamel) and a straight-down shadow to match the lantern above the far edge.
