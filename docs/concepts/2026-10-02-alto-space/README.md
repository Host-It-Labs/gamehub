# Alto space artwork (2 October 2026)

Alto is re-themed from floating sky islands to a cosy space theme: small friendly cargo spaceships fly between planets, load cargo (food, metal, ice, crystal) and bolt practical upgrades onto their own ship. Every image is a fresh generation from the text below only; no existing image was opened while writing the prompts (the 29 September README was read as text for the crop and calm-centre wording). Two variants per image (`-a`, `-b`), one Codex run each through `gen.sh` (`$imagegen`, newest Luna `gpt-6-luna` at low effort, Codex CLI 0.157.1, stdin closed, 15 minute kill), then `recover.sh` makes sure each output is that run's own PNG (wrong copies go to `wrong/`). Failed attempts keep a `-fail-N` suffix and are regenerated from the unchanged prompt.

Sources: `public/art/alto/*-v2-{a,b}.png`. Prompt files: `prompts/`. Run logs: `logs/`.
