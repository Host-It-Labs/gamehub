# UI direction concepts

## Decisions, 19 September 2026

- **Nox: "below deck", reworked as the captain's cabin.** Image 1 (`nox-belowdeck-landscape-v1-a`) is the closest. Changes for production: the oval chart table is clearly where the crew sits and plays, with an unobstructed ring of seating around it; cabin furniture only at the outer edges and only where it makes sense (desk, bunk, lantern, radio); stern windows show the sea far away; still dark; grain toned down a little. Nox keeps one special layout rule: each player's avatar, name and score sit at their own seat around the table, not in a top row.
- **Yata: toon-shaded arcade.** Image 8 (`yata-toon-landscape-v1-b`) is the pick as drawn.
- **Nox phone hand:** cards stack on two rows as in image 14 (`nox-opendeck-portrait-v1-b`), but only when one packed row would not fit; never horizontal scrolling.
- **Order of work:** production environment plates first (see `production-brief.md`), code once they are in `public/art/`.
- **Plates chosen (19 September, evening):** no generation met the strict band targets, so the closest were integrated with framing metadata absorbing the difference: Nox landscape `nox-cabin-landscape-v1-fail-2` (the only band pass; `fail-4` registered as the alternate "Cabin B"), Nox portrait `nox-cabin-portrait-v1-fail-4`, Yata landscape `yata-market-landscape-v1-fail-4`, Yata portrait `yata-market-portrait-v1-fail-4`. Geometry lives in `lib/games/*-world-*.json`; see the "Nox cabin and Yata night market" section of `docs/DESIGN.md`.

The 16 generated concepts are shown below in queue order. Each filename is placed directly above its image.
