# Mora phone boards and game-true covers (27 September 2026)

William: on phones the Mora boards spend too much room on scenery; the pads,
and so the creatures, should be bigger, the habitat text is too small, and the
place names should show (short ones). The box cover and the wide setup lid
showed fantasy moss creatures that are not in the game; the covers must show
the real world and the real animals.

Measured before the brief (390×844, accepted v3 tall boards): painted pads
about 30 CSS px, habitat scoring text about 9 px, no place name on phones.
Target: every pad and the ground below each group between 17–83% of the width
and 15–72% of the height of a 1024×1536 source, pads about a twelfth
(Observatory) or thirteenth (Floodline) of the width, places packed with
narrow paths between them.

Fresh built-in generations, newest Luna at low effort (`gen.sh`), no reference
images, two variants per image. Style paragraphs are copied verbatim from the
accepted v2 prompts (`../2026-09-25-mora-overgrown-2d/v2`). Prompt files:
`prompt-observatory-portrait.txt`, `prompt-floodline-portrait.txt`,
`prompt-cover-square.txt`, `prompt-cover-wide.txt`; Codex logs in `logs/`.

Outputs: `public/art/mora-phone-<world>-v4-<a|b>.png`,
`public/art/box-mora-game-v2-<a|b>.png` (square),
`public/art/box-mora-game-wide-v2-<a|b>.png` (lid, cut to 3:1).
