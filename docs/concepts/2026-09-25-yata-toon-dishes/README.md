# Yata dishes in the toon cover style (25 September 2026)

William asked for the dish tokens to follow the flat cel-shaded style of the Yata box and wide covers; the v2 dishes (gouache, detailed) read as too detailed and odd (Sesame as a black bun, Pickles as cucumber with orange). The style paragraph is the accepted wide-cover style text, adapted to a transparent single-dish token. Two fresh variants per dish (-a, -b), no reference images. Outputs: `public/art/yata-dishes-v3/`. Generator: `gen.sh` (Codex `$imagegen`, `-m gpt-6-astra`).
